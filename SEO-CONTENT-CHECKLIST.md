# SEO Content Checklist Template

Use this checklist every time you create or update a page.

---

## Page Information
- [ ] Page Title: _______________________
- [ ] URL: _______________________
- [ ] Main Keyword: _______________________
- [ ] Secondary Keywords (2-3): _______________________

---

## Meta Tags ✓

### Title Tag (55-60 characters)
- [ ] Includes main keyword
- [ ] Compelling and clickable
- [ ] Under 60 characters
- [ ] Title: _______________________

### Meta Description (150-160 characters)
- [ ] Includes main keyword
- [ ] Includes call-to-action
- [ ] Mentions "licensed chauffeurs" or "premium vehicles"
- [ ] Under 160 characters
- [ ] Description: _______________________

### Keywords Meta
- [ ] Includes all core keywords relevant to page
- [ ] Includes location if applicable
- [ ] Keywords: _______________________

---

## Content Structure ✓

### Headers
- [ ] H1 includes main keyword (only ONE H1)
- [ ] H2s include secondary keywords (2-4 H2s)
- [ ] H3s for subsections if needed
- [ ] Logical hierarchy maintained

### First Paragraph
- [ ] Main keyword in first 100 words
- [ ] Sets context clearly
- [ ] Includes marketplace positioning language
- [ ] Natural and readable

### Body Content
- [ ] Main keyword density: 1-2% (check: _____%)
- [ ] Secondary keywords present (0.5-1% each)
- [ ] Natural language (not keyword stuffing)
- [ ] Minimum 300 words
- [ ] Maximum 2000 words for best engagement
- [ ] Word count: _______

### Call-to-Action
- [ ] Clear CTA button/link
- [ ] Uses "Book Ride Online" or similar
- [ ] Links to booking page
- [ ] Appears early and at end

---

## Internal Linking ✓

### Required Links (3-5 per page)
- [ ] Link to homepage
- [ ] Link to fleet page
- [ ] Link to relevant service page
- [ ] Link to related content/blog
- [ ] Use anchor text with keywords

### Link Examples
- [ ] "private transfers" → /private-transfers/
- [ ] "chauffeur service" → /chauffeur-service/
- [ ] "luxury sedans" → /fleet/?category=luxury
- [ ] "book ride online" → booking page or homepage

---

## Images ✓

### Image Optimization
- [ ] All images compressed (under 200KB)
- [ ] Images have descriptive filenames (luxury-sedan-chauffeur.jpg)
- [ ] Width and height attributes set
- [ ] Lazy loading enabled

### Alt Text (Every Image!)
Template: "Professional [service] with [vehicle type] for [purpose]"

- [ ] Image 1: _______________________
- [ ] Image 2: _______________________
- [ ] Image 3: _______________________
- [ ] Image 4: _______________________

### Image Title Attributes
- [ ] All images have title attributes
- [ ] Titles include keywords where appropriate

---

## Schema Markup ✓

### Required Schema
- [ ] Breadcrumb schema added
- [ ] Service schema (if service page)
- [ ] Organization schema (if homepage)
- [ ] Review schema (if applicable)

### Schema Elements
- [ ] @context set to "https://schema.org"
- [ ] @type appropriate for page
- [ ] All required properties filled
- [ ] JSON-LD format validated

---

## Marketplace Positioning ✓

### Language Check
- [ ] Uses "compare" language
- [ ] Mentions "licensed chauffeurs"
- [ ] Mentions "verified providers" or similar
- [ ] Emphasizes "choose from" options
- [ ] Platform positioning (not service provider)

### Avoid These Phrases
- [ ] NOT using "we provide"
- [ ] NOT using "our drivers"
- [ ] NOT using "we offer"

### Use These Instead
- [ ] "Compare licensed drivers"
- [ ] "Browse premium vehicles"
- [ ] "Choose from verified providers"
- [ ] "Select your preferred chauffeur"

---

## Technical SEO ✓

### URL Structure
- [ ] Short and descriptive
- [ ] Includes main keyword
- [ ] Lowercase only
- [ ] Hyphens (not underscores)
- [ ] No unnecessary parameters

### Page Speed
- [ ] Images optimized
- [ ] CSS/JS minified
- [ ] Lazy loading enabled
- [ ] Page loads under 3 seconds

### Mobile Friendly
- [ ] Responsive design
- [ ] Text readable on mobile
- [ ] Buttons easily clickable
- [ ] No horizontal scrolling

### Canonical Tag
- [ ] Canonical URL set
- [ ] Points to correct page version
- [ ] No duplicate content

---

## Content Quality ✓

### Readability
- [ ] Short paragraphs (2-4 sentences)
- [ ] Bullet points used where appropriate
- [ ] Subheadings break up content
- [ ] Reading level: 8th grade or below

### Value to User
- [ ] Answers user questions
- [ ] Provides useful information
- [ ] Clear benefits stated
- [ ] No fluff or filler content

### Grammar & Spelling
- [ ] Spell-checked
- [ ] Grammar-checked
- [ ] No typos
- [ ] Professional tone

---

## Pre-Publish Checklist ✓

### Final Review
- [ ] All keywords naturally integrated
- [ ] All links working
- [ ] All images loading
- [ ] Schema validates (use Google's Rich Results Test)
- [ ] Page displays correctly on mobile
- [ ] Page displays correctly on desktop
- [ ] Call-to-action clearly visible

### SEO Tools Check
- [ ] Yoast/RankMath shows green (if installed)
- [ ] Google Search Console preview looks good
- [ ] Social media preview looks good (Facebook, Twitter)

---

## Post-Publish Actions ✓

### Within 24 Hours
- [ ] Submit URL to Google Search Console
- [ ] Share on social media
- [ ] Internal link from homepage/relevant pages
- [ ] Add to XML sitemap

### Within 1 Week
- [ ] Check Google Analytics for traffic
- [ ] Monitor for any crawl errors
- [ ] Check page is indexed (site:yoururl.com)
- [ ] Review bounce rate and time on page

### Monthly Review
- [ ] Check keyword rankings
- [ ] Review organic traffic
- [ ] Update content if needed
- [ ] Add more internal links if opportunity arises
