## 🔧 **Troubleshooting**

### **If Staff Portal doesn't load:**
1. Clear cache
2. Reactivate plugin
3. Check user permissions (must have `edit_posts`)
4. Check browser console for errors

### **If bookings don't sync:**
1. Go to Sync page
2. Click "Sync All Bookings Now"
3. Check source systems (CHBS, JetBooking)
4. Verify database tables exist

### **If inline editing doesn't work:**
1. Check browser console
2. Verify AJAX URL is correct
3. Check nonce is valid
4. Ensure user has permissions
